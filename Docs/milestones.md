# Kế hoạch 5 tuần

## Tuần 1 — Nền tảng sản phẩm

- Chốt MVP.
- Hoàn thiện sitemap.
- Hoàn thiện brandkit.
- Tạo wireframe.
- Chọn stack.
- Thiết kế database và API draft.

**Đầu ra:** tài liệu, wireframe, ERD và repo được tổ chức.

## Tuần 2 — Authentication và dữ liệu nền

- Khởi tạo frontend và backend.
- Đăng ký, đăng nhập, đăng xuất.
- Phân quyền người dùng/admin.
- Migration và seed.
- Admin quản lý danh mục thiết bị.

**Đầu ra:** người dùng đăng nhập được và admin quản lý danh mục.

## Tuần 3 — Chẩn đoán AI

- Form nhập triệu chứng.
- Upload ảnh.
- Tìm hướng dẫn liên quan.
- Tích hợp AI API.
- Validation structured output.
- Lưu kết quả chẩn đoán.

**Đầu ra:** luồng chẩn đoán chính chạy từ frontend đến database.

## Tuần 4 — Lịch sử và quản trị

- Lịch sử người dùng.
- Chi tiết kết quả.
- Phản hồi đã xử lý/chưa xử lý.
- Admin quản lý hướng dẫn.
- Admin theo dõi lượt chẩn đoán.
- Hoàn thiện responsive và trạng thái lỗi.

**Đầu ra:** MVP đủ chức năng.

## Tuần 5 — Hoàn thiện và deploy

- Kiểm thử.
- Sửa lỗi.
- Kiểm tra bảo mật cơ bản.
- Deploy frontend, backend và database.
- Thêm dữ liệu demo.
- Cập nhật README.
- Quay video demo.

**Đầu ra:** website online và repo sẵn sàng đánh giá.
