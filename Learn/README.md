# Learn

Thư mục lưu lại quá trình học và minh chứng tiến bộ trong 5 tuần.

## Cấu trúc

- `AI-Basic/`: Prompt, structured output, RAG và đánh giá kết quả AI.
- `UI-UX/`: Sitemap, user flow, wireframe và ghi chú kiểm thử giao diện.
- `Backend/`: REST API, authentication, authorization, validation và logging.
- `Data/`: Database, quan hệ bảng, migration, seed và dữ liệu nguồn.

## Cách cập nhật

Mỗi tuần nên thêm:

- Nội dung đã học.
- Điều đã áp dụng vào dự án.
- Vấn đề gặp phải.
- Cách giải quyết.
- Liên kết đến commit hoặc ảnh minh chứng.
